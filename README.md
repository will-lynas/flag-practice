# Flag Practice

Learn to identify country flags with spaced repetition at [flags.lynas.dev](https://flags.lynas.dev/).

Use Node.js 26. Run `npm ci --ignore-scripts`, `npm test`, then `npm run build` to produce the static site in `dist/`. With Google Chrome installed, run `npm run test:browser` against that build; set `FLAG_TEST_URL` to test a deployed URL instead.
